# Локальные шрифты постеров

Файлы используются без изменений. Во время создания постера браузер загружает их с нашего сайта, не из внешнего сервиса.

- `PosterStory.ttf` — Yeseva One Regular, https://github.com/google/fonts/tree/main/ofl/yesevaone, SIL Open Font License 1.1 в `PosterStory-OFL.txt`.
- `PosterScript.ttf` — Lobster Regular, https://github.com/google/fonts/tree/main/ofl/lobster, SIL Open Font License 1.1 в `PosterScript-OFL.txt`.
- `PosterDisplay.ttf` — Russo One Regular, https://github.com/google/fonts/tree/main/ofl/russoone, SIL Open Font License 1.1 в `PosterDisplay-OFL.txt`.
- `PosterSans.ttf` — DejaVu Sans, лицензия в `PosterSans-LICENSE.txt`.
- `Manrope.ttf` — шрифт интерфейса, лицензия в `OFL.txt`.
