# Мой герой — тест генерации

Интерактивная демонстрация персональных детских постеров. Здесь только готовый браузерный сайт: HTML, JavaScript, CSS, шрифты и авторские иллюстрации-примеры. Серверное приложение и история основного репозитория не входят в эту публикацию.

Подключён тест генерации через отдельный Cloudflare Worker. Ключ OpenAI хранится только в Cloudflare; в этом репозитории есть лишь публичный адрес сервиса. Пароль и код приглашения не требуются. По просьбе владельца общий и дневной пределы увеличены до 20 попыток — максимума текущего теста; ранее использованные попытки сохранены. Сайт публичный: посетитель со ссылкой может создавать постеры за баланс OpenAI API владельца в пределах общего лимита. Доступ к готовым результатам по-прежнему защищён случайным токеном браузера. Открытие сайта, загрузка фото, выбор темы, правки подписей и скачивание сами по себе не запускают генерацию. Для проверки можно выбрать «Попробовать с готовым примером» без личного фото.

## Что работает без API

Оформление подписей обновлено 30 октября 2026 года: шрифт, цвета и орнамент выбираются под тему. Режим «В цветах темы» можно заменить ручным цветом. Эти изменения и скачивание готового результата не вызывают платную генерацию. Новый сюжет требует отдельного запуска; его художественное качество оценивается по получившемуся изображению.

Для каждого нового заказа GPT сначала придумывает самостоятельный сюжет с учётом темы, стиля, возраста, пожеланий и недавних идей, затем модель изображений рисует его по фото. Библиотеки заранее написанных сцен нет. Один новый постер включает короткий платный текстовый запрос и не более одного запроса изображения. При ошибке придумывания готовая сцена не подставляется; перезагрузка не повторяет платные этапы. Описания сюжетов хранятся приватно до 24 часов и удаляются вместе с результатом.

Без обращения к OpenAI доступны загрузка и кадрирование, имя/возраст/класс, темы и стили, правки надписей и PNG/PDF из уже готовой иллюстрации. Новая нейросетевая иллюстрация расходует баланс API, пароль не нужен. Для полностью локального фотоколлажа разработчик может отключить адрес в pilot.json и пересобрать сайт.

Исходное фото хранится в браузере и передаётся через Cloudflare в OpenAI только по кнопке создания. Имя, класс и подарочная надпись не передаются: их добавляет браузер. Иллюстрация также хранится в закрытом хранилище Worker до 24 часов для восстановления; доступ защищён случайным кодом браузерной сессии. «Удалить мои фото и результаты» удаляет локальные данные и активную копию результата у Worker. Внешние провайдеры могут иметь отдельные сроки технического хранения и резервных копий. Подробности указаны на сайте в разделе конфиденциальности.

## Публикация

Ни ключи, ни переменные окружения, ни установка зависимостей для GitHub Pages не нужны. `index.html` расположен в корне. `.nojekyll` отключает ненужную обработку файлов. Лицензии шрифтов находятся в `fonts/`. Папка `examples/` содержит подготовленные иллюстрации, а не фотографии пользователей.

## Дизайн

Контрастная фиолетовая, коралловая и жёлтая палитра, крупные заголовки, плавная прокрутка мышью, появления блоков и мобильное меню. При настройке «уменьшение движения» анимации отключаются. Возрастные подборки 3–5, 6–8, 9–12 и 13–17 лет передают рекомендацию в конструктор, сохраняя доступ ко всем темам.

Портрет в примере специально создан для демонстрации и изображает вымышленного ребёнка. Это не загрузка пользователя и не свидетельство сходства при генерации. Подробности — в examples/ASSETS.md. Интерьер, рамка и упаковка показаны как визуализации.

Сервис пока не принимает заказы и оплату. Печать и доставка обозначены как будущие возможности: материалы, комплектация, цены и сроки не объявлены.

## Выбор стиля и темы

Сначала выбирается стиль рисунка: мультяшный, объёмный 3D, акварель, комикс, аниме, графический постер или художественный портрет. Доступен автоподбор по возрасту. Миниатюры стилей — условные авторские иллюстрации; нейросетевая обработка в демо не выполняется.

В каталоге ровно 30 готовых тем в пяти категориях: «Игры и герои» (7), «Спорт и сцена» (7), «Сказки и приключения» (8), «Животные и природа» (5), «Открытия и свой стиль» (3). Есть поиск по русским названиям и отдельное поле своей идеи. Выбранный стиль и тема сохраняются при возврате и обновлении страницы.

Класс автоматически оформляется как `5 «Б» класс`: можно вводить `5Б`, `5 б` или `5 Б класс`. Правило одинаково для просмотра, PNG и PDF, в том числе для ранее сохранённых результатов.

## Фото с iPhone · 25 октября 2026

Поддерживаются HEIC/HEIF (до 15 МБ и 40 МП), JPEG, PNG и WebP. Фото автоматически преобразуется в браузере, с правильным поворотом; внешние сервисы конвертации не используются. Загружаемый при необходимости локальный декодер и лицензии находятся в `heic/`.

На iPhone после подготовки PNG/PDF нажмите «Сохранить PNG/PDF»; при поддержке браузером доступна «Поделиться / Сохранить». Есть ссылка «Открыть файл». Кириллица в PDF сохраняется. Поля адаптированы к мобильному вводу, данные восстанавливаются после обновления страницы. Проверены Chromium и WebKit с профилем iPhone 13; физическое устройство и системные окна iOS в облаке недоступны.
