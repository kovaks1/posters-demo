# Мой герой — демонстрация

Интерактивная демонстрация персональных детских постеров. Здесь только готовый браузерный сайт: HTML, JavaScript, CSS, шрифты и авторские иллюстрации-примеры. Серверное приложение и история основного репозитория не входят в эту публикацию.

Фото, имя, класс и результаты обрабатываются локально в браузере посетителя и не отправляются в GitHub или сервис нейросети. Не используйте общий браузер для личных фотографий. Можно пройти сценарий с кнопкой «Попробовать с готовым примером», не загружая личное фото.

## Открыть сайт

Демоверсия: https://kovaks1.github.io/posters-demo/

Скриншоты компьютера и телефона: https://kovaks1.github.io/posters-demo/review/

Настройки репозитория: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. После успешной публикации GitHub покажет **Visit site**. До включения публикации ссылка может отвечать 404.

## Что работает без API

Фото → кадрирование → имя, возраст и класс → тема и стиль → демонстрационный фотоколлаж → правка подписи → PNG/PDF А4 или А3 с кириллицей. Результат явно помечается как демонстрация. Художественная нейросетевая перерисовка здесь не выполняется.

Данные сохраняются в локальной базе браузера для восстановления после обновления. Доступ действует до 24 часов; истёкшие записи очищаются при следующем открытии/действии на сайте. «Удалить мои фото и результаты» удаляет их раньше. Закрытая вкладка не выполняет очистку по расписанию. Уже скачанные файлы удаляются отдельно на устройстве.

## Публикация

Ни ключи, ни переменные окружения, ни установка зависимостей для GitHub Pages не нужны. `index.html` расположен в корне. `.nojekyll` отключает ненужную обработку файлов. Лицензии шрифтов находятся в `fonts/`. Папка `examples/` содержит подготовленные иллюстрации, а не фотографии пользователей.

## Дизайн

Контрастная фиолетовая, коралловая и жёлтая палитра, крупные заголовки, плавная прокрутка мышью, появления блоков и мобильное меню. При настройке «уменьшение движения» анимации отключаются. Возрастные подборки 3–5, 6–8, 9–12 и 13–17 лет передают рекомендацию в конструктор, сохраняя доступ ко всем темам.

Портрет в примере специально создан для демонстрации и изображает вымышленного ребёнка. Это не загрузка пользователя и не свидетельство сходства при генерации. Подробности — в examples/ASSETS.md. Интерьер, рамка и упаковка показаны как визуализации.

Сервис пока не принимает заказы и оплату. Печать и доставка обозначены как будущие возможности: материалы, комплектация, цены и сроки не объявлены.

Запись реальной прокрутки и анимаций (16 секунд, MP4), а также новые снимки компьютера и телефона: https://kovaks1.github.io/posters-demo/review/

## Выбор стиля и темы

Сначала выбирается стиль рисунка: мультяшный, объёмный 3D, акварель, комикс, аниме, графический постер или художественный портрет. Доступен автоподбор по возрасту. Миниатюры стилей — условные авторские иллюстрации; нейросетевая обработка в демо не выполняется.

В каталоге ровно 30 готовых тем в пяти категориях: «Игры и герои» (7), «Спорт и сцена» (7), «Сказки и приключения» (8), «Животные и природа» (5), «Открытия и свой стиль» (3). Есть поиск по русским названиям и отдельное поле своей идеи. Выбранный стиль и тема сохраняются при возврате и обновлении страницы.

Класс автоматически оформляется как `5 «Б» класс`: можно вводить `5Б`, `5 б` или `5 Б класс`. Правило одинаково для просмотра, PNG и PDF, в том числе для ранее сохранённых результатов.

## Узнаваемые миниатюры

Обновлены 30 тем и 8 вариантов выбора стиля. У Minecraft показан Стив, у Brawl Stars и Roblox — логотипы, у персонажных тем — соответствующие персонажи. Остальные темы представлены предметными иллюстрациями в единой палитре. Для художественных стилей подготовлены изображения вымышленного героя в разных техниках.

Все 38 миниатюр — локальные WebP 640×400, общим объёмом около 1,25 МБ. Источники указаны в examples/ASSETS.md и examples/choices/SOURCES.md. Сайт не загружает картинки со сторонних сайтов. Образцы не являются обработкой пользовательского фото; демонстрационный режим сохранён.

Новые скриншоты: https://kovaks1.github.io/posters-demo/review/?v=visual-20261024
