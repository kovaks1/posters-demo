# Примеры постеров

12 готовых постеров переданы владельцем проекта для размещения на сайте. Персонажи созданы с помощью ИИ для демонстрационных примеров. Оригиналы не публикуются; WebP оптимизированы без обрезки композиции и без EXIF-метаданных. Записи SHA-256 в lib/poster-showcase-assets.json относятся к исходным файлам.
